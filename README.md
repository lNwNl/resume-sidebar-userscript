# 简历侧边栏

这是一个用于 Chrome + Tampermonkey 的简历字段侧边栏。先点击招聘网页中的目标输入位置，再点击侧边栏里的字段，即可尝试填入。仓库中的 `简历侧边栏.user.js` **只包含虚构示例和明显的占位值**，安装前应先把示例替换为自己的真实资料。

## 交给 AI 定制

最常见的用法是把本仓库的 `README.md`、`简历侧边栏.user.js` 和你愿意提供给 AI 的简历资料放在同一个本地工作区，请 AI 修改脚本。可以直接使用下面的提示词：

> 请阅读 README.md 和简历侧边栏.user.js。根据我提供的简历、个人档案或证明材料，只修改脚本中 `const layouts = [...]` 的分类、条目和字段值；如果需要新字段，可使用现有的 `text`、`date`、`period`、`item` 辅助函数。删除所有不适用的示例分类和占位值。只写有材料支持的事实，不编造日期、职责、成果、证书或链接。若只有年月而没有具体日期，用文本字段保留年月，别假定某一天；如果我需要填写原生日期控件，先向我询问准确日期。保留侧边栏界面、填写逻辑和 Tampermonkey 元数据。完成后检查脚本语法，并逐项检查仍有哪些示例值或不应披露的信息。请把定制版留在本地，不要提交到公开仓库。

`layouts` 是唯一需要替换的简历数据区，结构如下：

```js
{ name: '分类名', fields: [text('字段名', '字段值')] }
{ name: '分类名', items: [item('经历标题', [text('字段名', '字段值')])] }
```

- `text(label, value)` 用于普通文本，也可用于选项文字；点击原生下拉框、单选框或常见 ARIA 选项时，脚本会尝试按文字匹配。
- `{ ...date('2024-06-15'), label: '获奖时间' }` 用于**确切到日**的日期，格式必须是 `YYYY-MM-DD`。填写 `type=month` 时脚本会取年月。
- `...period('2024-06-15', '2024-08-31')` 一次生成“开始时间”“结束时间”“起止时间”三个字段；第二个参数为 `null` 时表示“至今”。若只知道年月，可改用三个 `text` 字段记录真实年月，避免补造日期。
- `name` 和 `label` 是显示在侧边栏中的标题；`value` 是点击后要写入网页的内容。同一段经历放在一个 `item` 内，避免把不同经历混在一起。

可以增删分类、经历和字段。没有论文、证书或家庭信息时，直接删除对应分类；身份证号、住址、家庭信息等只有在目标表单确实要求、本人愿意提供时才加入**本地定制版**。不要把定制版、原始简历或证明材料上传到本公开仓库，也不要贴到公开 Issue 或 PR。

## 安装与填写

1. 在 Chrome 安装 Tampermonkey，并在它的管理面板创建新脚本。
2. 把已定制的 `简历侧边栏.user.js` 全部内容粘贴进去并保存。不要直接把仓库里的虚构示例用于正式申请。
3. 打开招聘网页，点击右下角“简历侧边栏”，再点击网页中的目标输入框、表格单元格或选项。
4. 展开分类并点击需要填写的字段，检查网页**实际显示**的内容。日期、下拉选项和网站自定义控件尤其需要核对。

初始时所有分类收起；打开分类会展开其中第一条经历，之后可同时展开多条。搜索会直接列出命中字段。`Alt` + 点击字段只复制，不填写；自动填写失败时也会复制并提示手动粘贴。将鼠标停在侧边栏的 `?` 上可查看提示。

侧边栏默认宽度为 350 像素，可拖动左边缘或用键盘左右方向键调整。字号可调；外观可选浅色、深色或跟随浏览器。宽度、字号和外观保存在 Tampermonkey 本地存储中，展开状态不跨页面保存。

脚本支持常见输入框、文本域、可编辑区域、表格中的普通控件、原生日期/年月控件，以及一部分原生和 ARIA 选项。网站自己的日期弹层、复杂下拉框、封闭 Shadow DOM 或文件上传框可能无法自动填写，此时使用复制功能。iframe 中的普通字段也会尝试填写。脚本不会自动提交表单。

## 公开版与个人版

本仓库只维护可公开的示例脚本。任何包含真实身份、联系方式、经历或家庭信息的版本都应保存在使用者自己控制的私有位置。修改数据时请保留 `@namespace`、消息通道和本地设置键，以免不同版本在同一页面互相干扰；如果安装多个不同的个人版，则分别更换这三个标识。
