# 📝 简历侧边栏 (Resume Sidebar)

这是一个用于网页端的 Tampermonkey（油猴）用户脚本。它可以为您在网页右侧生成一个**专属的简历数据侧边栏**。

在投递简历、填写繁琐的招聘表单时，只需**先点击网页输入框，再点击侧边栏对应的字段**，即可一键自动填写，大幅提升投递效率。

---

## 🚀 核心功能

- **一键填写**：支持普通的文本框、文本域，以及原生的日期、下拉菜单、单选/复选框。
- **智能复制**：遇到无法自动填写的复杂/自定义控件，脚本会自动将内容复制到剪贴板，方便你手动 `Ctrl+V` 粘贴。
- **强制复制**：按住 `Alt` 键点击侧边栏字段，只复制不填写。
- **快速搜索**：支持在侧边栏顶部搜索经历或字段名。
- **UI 可调**：可随意拖拽调整侧边栏宽度，支持浅色/深色模式及字号调整。

## 🛠️ 如何配置你的专属简历（重要）

仓库中提供的 `简历侧边栏.user.js` **只包含虚构的示例数据**。在使用前，你必须将脚本中的数据替换为你自己的真实简历。

### 推荐方法：交给 AI 帮你一键定制
将本脚本代码和你的个人简历（文本/PDF/Word等）一起发给 ChatGPT / Claude / DeepSeek 等 AI 工具，并发送以下提示词：

> “请阅读这段油猴脚本代码和我提供的简历资料。请帮我把简历内容填入代码中的 `const layouts = [...]` 数组中。
> 要求：只使用 `text`、`date`、`period`、`item` 等内置函数，严格按照现有格式生成。没有对应的分类请删除，不要编造任何虚假信息。`date` 和 `period` 只能使用资料中明确到日的日期；如果资料只有年月，请使用 `text` 保留原始年月，不得补成 1 日、30 日、月末或其他具体日期。请直接输出修改后的完整 `layouts` 代码块给我。”

### 手动修改方法
如果你想自己动手，只需在脚本代码中找到 `const layouts = [...]` 这一段，按照以下格式修改你的数据：

```javascript
const layouts = [
  { 
    name: '基本信息', // 分类名称
    fields: [
      text('姓名', '张三'),                  // 普通文本 text('标签', '内容')
      text('电话', '13800138000'),
      { ...date('2000-01-01'), label: '出生日期' } // 准确到日的日期
    ] 
  },
  { 
    name: '教育经历', 
    items: [
      item('XX大学 · 本科', [                // item 表示一段具体的经历
        text('学校', 'XX大学'),
        ...period('2018-09-01', '2022-06-30') // 生成开始、结束、起止时间三个字段
      ])
    ] 
  }
];
```

日期不会由脚本自动补全或推断。`date('YYYY-MM-DD')` 只用于已经确认到日的日期；`period` 的两个日期参数也必须来自真实资料。例如只知道 `2024.06` 时，应写成 `text('开始时间', '2024.06')`，不要改写为 `date('2024-06-01')`。

## 💻 安装与使用教程

### 1. 安装脚本
1. 在浏览器安装 [Tampermonkey (油猴) 扩展](https://www.tampermonkey.net/)。
2. 点击油猴图标 -> **添加新脚本**。
3. 将你**配置好真实数据的脚本代码**全部粘贴进去，按 `Ctrl + S` 保存。

### 2. 开始使用
1. 打开任意招聘网站的简历填写页面。
2. 页面右下角会出现一个 **“简历侧边栏”** 的悬浮按钮，点击展开。
3. **操作两步走**：
   - 第一步：鼠标点击网页中需要填写的输入框（让光标在里面闪烁）。
   - 第二步：点击侧边栏中对应的字段。内容就会神奇地填进去啦！
4. **遇到填不进去的情况**：留意屏幕右下角的黑色提示弹窗，如果提示“未接受该值已复制”，请直接在网页输入框里按 `Ctrl + V` 粘贴。
